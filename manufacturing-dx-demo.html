01 / MANUFACTURING DX 架空データ · v0

入力情報を、現場の作業量へ。

品番を作業区分につなぎ、日別の数量を予定工数に変える。製造DX基盤の「整える → 集計する → 作業量を見通す」を体験する公開デモです。

実運用の構造を説明する簡略モデルです。実社名・実品番・実図面・実顧客・社内データは使用していません。

INPUT → 品番／ルール照合 → 作業区分確定 → DAY LIST / CROSS LIST → 作業区分別標準時間照合 → WORKLOAD

デモを読み込んでいます。表示が進まない場合は、HTMLと2つのJSファイルを同じフォルダに置き、JavaScriptを有効にして開いてください。

INPUT ／ 元の入力

まず元明細を保持します。品番に一致するルールを探し、作業区分とラインを確定します。問題のある値も書き換えず、確認対象として残します。

品番・材料の共通台帳を見る

同じ品番ID・材料IDを、今後の図面検索・原盤発注でも参照する想定です。材料と取数はこのデモの工数計算には使いません。

DAY LIST ／ 日別明細

計画日・ライン・案件で並べ、各明細を作業区分へつなぎます。数量と作業区分が確定した明細を掲載します。標準時間が未登録の明細も数量は保持します。

CROSS LIST ／ 品番 × 計画日

DAY LISTと同じ明細を日付ごとに集計します。点線「—」はその日の明細なし。確認対象の入力を数量0として埋めるものではありません。

標準時間 ／ 作業区分で照合

品番から直接時間を決めず、ルールで確定した作業区分の標準分／個を参照します。同じ作業区分の品番は、同じ標準時間を使います。

予定工数（分）＝ 数量（個）× 作業区分の標準時間（分／個）

WORKLOAD ／ 予定工数

数量に作業区分別の標準時間を掛け、計画日・ラインごとの作業量を見通します。標準時間のない数量は「未計算」とし、計算できた分と分けて表示します。

棒の長さは表示中の最大値に対する相対表示です。設備能力・稼働率・能力超過を表すものではありません。

確認対象

確認動作を示すため、4種類の不備を含めています。この一覧は絞り込みにかかわらず全件を表示します。

    未登録品番・作業区分未解決・数量不正は日別／クロス集計に含めません。標準時間欠落は数量集計に残し、工数を未計算にします。

    対象期間：2026年4月6日〜10日（架空の計画日）。名称・材料仕様・取数・数量・標準時間は、すべて公開用に新規作成した架空の設定です。

    v0：品番完全一致のルールで1つの作業区分を確定。段取り時間、能力超過判定、予実比較、CSV入出力、保存、自動日程計画は対象外です。
